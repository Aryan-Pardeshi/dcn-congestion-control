# Congestion Control Lab

Interactive lab experiment for Data Communication & Networks (Module 4.2, The Network Layer in the Internet). Explore congestion control algorithms — traffic shaping with Leaky Bucket and Token Bucket, feedback congestion control with Choke Packet, and active queue management with RED — in a React simulation of three sources sending through router R1 over a bottleneck link to a server.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

## Test

```bash
npm test
```

## Build

```bash
npm run build
```
